# Brayan Rodríguez

Desarrollador de software enfocado en backend y sistemas de información, especializado en PHP y Laravel. Experiencia en el desarrollo de sistemas administrativos e institucionales en producción, orientados a la gestión de procesos, auditorías y control de datos.

Actualmente participo en el desarrollo del sistema institucional SIVECA (Sistema de Verificación del Desempeño Ambiental), implementado para la gestión de auditorías ambientales, licencias y procesos administrativos en la Dirección de Verificación del Desempeño Ambiental (DIVEDA).

## 🏛️ Experiencia

### Sistema SIVECA (DIVEDA)
Sistema institucional en producción para la gestión de auditorías ambientales, licencias, auditores y procesos administrativos.

🔗 Proyecto: *https://siveca.miambiente.gob.pa/*

- Registro y gestión de auditores naturales y jurídicos
- Control de licencias y estados de auditoría
- Gestión de planes de auditoría y planes ambientales (PAMA)
- Flujos de solicitudes, correcciones y aprobaciones
- Sistema en uso dentro de entorno institucional

### Sistema de Conciliación Bancaria
Sistema web para gestión de cheques, transacciones y conciliaciones financieras.

- Registro de movimientos financieros
- Control de cheques y reportes administrativos
- Gestión de datos contables en interfaz web

- Gestión de clientes y servicios

- Flujo básico de operaciones del negocio
